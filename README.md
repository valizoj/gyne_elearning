# 産婦人科実習の1週間

大学病院 A-2・B-3 の配付資料画像2枚をもとにした、スマートフォン向け静的Webアプリです。

- 動画19件（配付資料の時間を合計すると330分）、プリント1件、国家試験対策問題1件、実習終了後アンケート1件。
- QRコード全22個をローカルのZXing-C++でデコード。URLの推測・短縮URLの置換はしていません。
- A-2／B-3切替、曜日フィルター、教材・予定の検索、未チェックのみ表示。
- 学習チェックは端末のlocalStorageに保存。動画の視聴完了・テスト提出と連動しません。
- manifest、Service Worker、iPhoneホーム画面用アイコンを同梱。
- 外部フォントやアクセス解析、サーバーへの進捗送信はありません。

## GitHub Pagesで公開する

このフォルダーの内容をリポジトリのルートに配置します。ビルド作業は不要です。

1. リポジトリの **Settings → Pages** を開く。
2. **Build and deployment → Source → Deploy from a branch** を選択。
3. **main / (root)** を選び **Save**。
4. 公開先は `https://valizoj.github.io/gyne_elearning/`。

コミットするだけではPagesの公開設定は有効になりません。公開完了まで数分かかる場合があります。

## iPhoneでホーム画面に追加

公開URLをSafariで開き、共有メニュー → **ホーム画面に追加** → **追加**。
「Webアプリとして開く」が表示された場合はオンにします。

一度読み込んだ予定とリンク一覧はオフラインでも利用できます。動画、Google Drive、各フォームは外部サイトで開き、通信や提供元のアクセス権が必要です。iPhone実機での動作確認は未実施です。

## 転記とリンクの扱い

`source-data.json` に予定・案内・教材名・時間・小テスト表記・読取URL・元画像でのQR左上座標を保存しています。同じデータを `index.html` に埋め込んでいます。原画像そのものは公開ファイルに含めていません。

- 画面用に改行・空白・一部の全角半角を整形しています。
- 午前午後の指定がない予定には表示上「終日」というラベルを付けています。資料に時間帯の明記はありません。
- アンケートは大学病院・県総合の全実習終了後の案内です。
- 「小テストあり」は資料の記載です。独立した小テストURLは原画像にはありませんが、対象13動画の説明文から取得し追加しています。
- QRを読み取れたことと、リンク先が現在公開されていることは別です。小テスト対象13動画の説明文は確認しました。フォーム内の設問・回答・提出は確認していません。
- 動画の複製やフォームの回答・送信は行っていません。
